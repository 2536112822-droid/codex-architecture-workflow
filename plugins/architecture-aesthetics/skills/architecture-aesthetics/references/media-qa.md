# 分媒体审美审查与精度边界

本模块提炼可迁移的审美规则、辅助大胆探索、定位问题并提出返修要求。充分使用当前实际可用的高能力多模态与图像生成工具进行参考拆解、跨域迁移、构图推演、局部或整体重构及视觉复核。`su-model`、`cad-tz-model`、`rhino-model`、`presentations` 等专业技能负责原生编辑、数值验证、保存及交付；此处不重复建立操作流程。

## 按任务选择自由度

- **探索新设计**：按 brief 可大改体量、布局、材质、镜头和叙事，鼓励有根据的跨案例迁移与新方案。参考和现状图不自动成为锁定目标；保留真实场地事实、明确的项目硬要求及用户指定保护项。新方案不能冒充已建现状或已验证的原模型。
- **优化已确认成果**：先识别哪些内容已被用户确认、哪些是本次任务要求保持的对象，仅对这些内容启用保护。相机、布局和材质均不默认锁定；任务需要比较同一对象时，使用可比的基准视图。
- 下述维度是可选诊断工具，按任务、风险和证据选择。不要设固定全量清单、统一审美总分、统一低饱和风格或强制循环次数。复用当前修订已有证据；质量已满足任务且没有未解决的关键问题时结束，出现新问题再追加针对性验证。

## 共同判定

- 将审美软偏好与硬约束分别报告。适用的真实测量与技术标准保持有效；在此范围内，依次依据当前授权与明确保护范围、项目风格、长期个人偏好。冲突要说明，不能静默混合。
- 硬门状态仅用 `pass / fail / unknown / not_applicable`。`pass` 必须有同一目标修订、适用范围内的证据；`unknown` 不能折算成通过。关键硬门失败时不能宣称可交付，关键证据缺失时不能宣称精度或合规已验证；仍可给出范围明确的审美意见。
- 几何失败、数值不符或错误技术信息不能被高审美评价抵消。默认使用有依据的分维度诊断和相对改进，不生成统一审美总分。
- 审查问题尽量定位到页码、画面区域、构件或图层，连接“观察→对当前目标的影响→具体修正”。比较迭代时使用可比内容和视图，允许原方案更好；模型评审必须看到实际成果，不能只评文字摘要。真实用户 A/B 选择用于判断审美效果，存入长期库前仍须完成本轮保存询问。
- 每条观察标记 `fact / inference / unknown`：画面可见现象可为事实；隐藏构造、材料真实参数与成因通常是推断或未知。参考图不能自行证明尺寸、耐久性、结构安全或当地法规适用性。
- 制图规则记录 `region`、`standard`、`edition`、`clause_or_project_rule`、`source`、`verified_on`、`applicability`、`units` 与所需阈值。核实来源及项目适用范围后才设硬门；课程、事务所约定应标为项目规则。不得自造通用线宽、字体字高、标注精度或出图比例数值。

## 审查范围

| domain | 审美维度 | 适用硬门与原生证据 | 仅凭像素不能验证 |
|---|---|---|---|
| `architecture` | 体量与比例、虚实和开口节奏、尺度层次、场地关系、材料与构造表达、空间叙事；指出参考中可迁移的原理及不适用条件 | 真实场地事实、当前明确的功能/尺寸要求和指定保护项；探索范围内的原布局与形式允许重构；技术结论需图纸、模型或已核实资料支持 | 实际净尺寸、隐藏空间与结构、用地边界、功能或法规合规、材料性能 |
| `presentation` | 叙事顺序、标题层级、网格对齐、留白、图文比例、跨页一致性、色彩与图例、投影阅读 | 页码/图名/单位/数据及来源准确；正文不溢出、关键内容不遮挡；受影响页面在真实输出尺寸下渲染可读，未改页复用有效证据；编辑文件与最终导出对应 | 可编辑性、字体与链接是否完整、原始数据真实性、投影现场可读性；截图中的清楚不证明导出完整 |
| `model` | 材质尺度与方向、UV、粗糙度与反射层次、细节密度、构件接缝、光照及场景表达 | 由 SU/Rhino 记录单位、公差、目标 ID/GUID、修订和受保护几何；修改材质后独立复核保护项；要求实体或可制造性时运行相应原生检查 | 几何闭合、重面、非流形、隐藏构件、真实尺寸、完整 UV 或全部场景状态 |
| `render` | 材料可辨性、纹理尺度、光照层次、曝光与白平衡、反射、接触关系、环境与人物尺度、镜头和构图 | 保真任务记录源修订及相机/投影/裁切，并核对本次明确保护的门窗、边界、柱网等；局部修改任务用区域约束，整体探索允许整体重构；技术文字和标注由真实内容生成 | 任意 AI 生成区域的真实几何、隐藏背面、多视角一致性、物理材质参数、日照时刻与方向准确性 |
| `cad` | 线条层级、图面疏密、注释避让、轴网与尺寸组织、符号及图框一致性、出图阅读 | 原生单位、几何量测、实际尺寸与标注覆盖值、图层/线型/线宽/文字样式、布局与打印比例；按项目适用规则核验，定位到实体；天正对象语义经原生工具复查 | 真实标注关联、隐藏/冻结图层、外参完整性、单位与比例、重复重叠实体、对象语义或全套标准符合性 |

图板、分析图或演示页出现分组不清、错位/溢出、文字背景对比不足或色阶疑点时，按需读 [graphic-diagnostics.md](graphic-diagnostics.md) 的对应部分；没有相关问题不增加检查步骤。

## 方案思路审查

方案思路的审查另看 [design-ideas.md](design-ideas.md)：说明文字提出的策略是否在图纸/空间关系中体现，有何体验价值、条件与代价。概念精彩、画面漂亮和技术可行是不同结论，分别依据实际证据判断；仅文字方案的思想讨论不套用同相机检查。

## 同相机对照与保真

1. 同相机要求用于几何保真的直接图像比较，不限制新方案或新镜头的探索。需要这种比较时，使用同一源模型修订、相机位置/朝向、焦距或正交投影、画幅和裁切；记录基准图与候选图。条件不匹配时先校正，无法校正则标 `unknown`，不能把透视差直接判成几何错误。新方案改动另按 brief 检验，不以偏离旧图为错误。
2. 分别检查轮廓、开口、柱网、接缝和关键构件。源模型 ID 与数值检查负责真实几何；图像叠加、边缘偏差或区域重叠指标只用于告警，阈值按图像尺度和本项目保护要求设定。
3. 有深度/线稿控制的 AI 输出仍可能增删门窗、融合构件或改写遮挡关系。对于要求保留已确认几何的交付，用真实模型基础渲染及适用控制，并保存基准和修改范围；遮罩是否需要取决于保护对象及本次修改范围。允许的新设计可以大幅重构，但需在原生模型落实后才能宣称几何已验证。未经验证不得使用“完全保真”“尺寸准确”等表述。
4. 光照调整会改变阴影与可见边缘；需区分光影边缘和真实构件轮廓。单视图相似不能证明多视图一致，未查看角度保持未知。

## 去 AI 味：用可观察问题代替来源猜测

只报告实际看到的缺陷及位置，不因画风或检测器分数断言作者使用了 AI。也不要通过统一颗粒、脏污、暗角或褪色来机械地“去 AI”。按需检查：

- 材质纹理是否有合理尺度、方向和连续性；是否出现复制图案、拉伸、过度平滑、塑料般反光或不相干细节。
- 墙体、洞口、檐口、板边、栏杆是否有可信厚度与连接；门窗是否融合、重复、突然中断，构件是否悬浮或穿插。
- 直接光、阴影、反射是否相互解释；接触阴影是否缺失或过重；玻璃中反射的构件是否对应场景。
- 人物、树木、家具与建筑尺度是否协调；肢体或轮廓是否畸变；景物是否重复贴图、边缘光晕或遮挡不一致。
- 文字、数字、标识和技术图例是否可读且真实；是否出现乱码、伪细节、过锐边缘、过度 HDR、泛光或不必要的电影化处理。

## 可定位问题记录

修正优先级按对本次结果的影响安排：先处理事实/精度错误和主要表达障碍，再处理有可见收益的局部细节。不要为微小风格差异重做整个成果；复核已经改动的部位及可能受影响的保护项，足够满足目标就结束。

按任务选择记录形式，普通审美交流只需能说清**位置、观察、理由、修正**，可以直接写成一句话或短表。需要精度验收或机器交接时，再按需增加修订、规则来源、证据和验证字段；不要为填写记录打断创作。

```json
{
  "location": "<页码、场景、构件或画面区域>",
  "observation": "<可见或量测的问题>",
  "reason": "<为何影响表达或违反适用要求>",
  "suggested_fix": "<针对问题的具体改进，可为局部返修或整体重构>"
}
```

可选交接字段：`issue_id`、`domain`、`severity`、`evidence_level`、`artifact.path/revision`、`entity_ids`、`bbox_normalized`、`expected`、`rule_source`、`evidence`、`gate_status`、`preserve`、`verification`、`unknowns`。只提供当前任务真正需要且有依据的字段。

采用 `severity` 时可用 `hard_blocker / major / minor`；软偏好问题的 `gate_status` 为 `not_applicable`。如需归一化边框，顺序为 `[x_min, y_min, x_max, y_max]`，原点在左上角；未量得边框就省略，不编造坐标。CAD/模型交接优先附实体 ID/GUID，PPT 交接优先附页码与元素标识。返修后的精度结论依据实际证据更新，保留仍未知的项目。
