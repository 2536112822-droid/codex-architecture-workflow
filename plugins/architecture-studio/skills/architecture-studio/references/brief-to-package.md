# 任务书到协调成果

用于从任务书发展整套方案，或需要模型、CAD、彩平、指标相互一致的任务。按实际交付范围采用相关部分；局部修改直接复用现有记录，无需新建整套表格或重新设计已确定内容。

## 按建筑阶段的结果选择工作

下面是结合专业资料对本工作流的适配，不是将某个国家的执业/审批流程原样套入课程作业。[RIBA Plan of Work 2020](https://www.riba.org/media/sszn5kkt/2020ribaplanofworktemplatepdf.pdf)以阶段结果和信息交接覆盖需求至使用；[NSW建筑师注册委员会的工作流程说明](https://www.architects.nsw.gov.au/using-an-architect/working-with-your-architect)将前期可行性、设计与后续委托范围相联系；[AACA 2021能力框架](https://aaca.org.au/national-standard-of-competency-for-architects/performance-criteria/)补充迭代设计、文化/环境与技术整合。查阅日期2026-09-26；这些不是本项目新的课程要求或合规证明。

| 当前设计阶段 | 应解决的问题 | 按任务选择足够的成果/推进依据 |
|---|---|---|
| 需求与可行性 | 要改善什么、为谁服务，场地/资源是否容纳目标 | 简短回应任务书、功能/容量与资源假设、关键限制；有需要时比较改造/试点/新建等途径，不重复发散已确认目标 |
| 概念方案 | 哪种空间策略最能回应任务和场地 | 有实质取舍的布局/剖面/体块和采用理由；参考需转成设计关系，不能只选外观风格 |
| 空间协调 | 功能、流线、结构和环境策略能否一起成立 | 对应的主要平剖、关键接口或代表性样段，查会改变布局的冲突与必要估算 |
| 技术深化与文件 | 选定设计如何被准确制作/建造及协同理解 | 按委托/课程深度协调尺寸、构造、材料性能、图纸与说明；标明仍需专业意见或现场证据的条件 |
| 制作/建造（任务涉及时） | 实际过程是否落实设计，变化如何处理 | 原型/现场记录、变更依据和适用核验；不把模型完成当作建造完成 |
| 交接与使用（任务涉及时） | 接手者能否继续使用/维护，实际表现如何 | 所需源文件/资料和接续说明；真实使用观察再回到原目标和反馈机制，不能用渲染图代替使用评价 |

学术方案、规划演示和局部工具操作只进入实际需要的阶段。方案的“一年/十年”是时间范围，不代表已经达到施工或使用阶段；已选定方向沿用，后续修订仍按受影响部分回查。完整生命周期是定位遗漏的参考，不能变成每轮全套交付或每阶段重复审批。

## 在空间定型前协调关键问题

- 从任务和已有资料明确本次使用者/活动、功能容量、相邻与分离关系、主要到达/服务路线和使用时段；关注用户体验与场所意图，不以面积满足代替空间质量。相关使用者、运营者或社区意见注明实际来源；缺少的意见保留假设，不能把AI推测写成已咨询，文化/Country相关知识同样保留真实来源与适用范围。
- 选出最可能迫使方案返工的少数关系，用合适的平面、剖面、示意计算或样段一起检查。例如开口/通路与承重关系、楼层高度与设备空间、朝向/采光/通风与体块、材料回收/建造顺序与连接、分期投入与持续运营。这里只是选题线索；按阶段深度采用可信参数或明确假设，不强制所有专业计算，也不虚构专业审查结果。
- 当目标涉及环境表现、建造成本、工期或维护时，在方案取舍中带入同口径的约束/估算和不确定性，随后再随设计深化更新；渲染材质和“绿色”标签不证明性能。需要专业意见、现场测量或真实使用反馈的关键依赖，记清所缺信息、影响对象与获得/验证时点，未取得只限制依赖结论。
- 深化前用一句话或已有阶段记录说明本阶段要解决的问题、将展示的成果和继续推进依据。信息细度由下一步判断决定：先解决会改变布局/系统的疑点，再增加重复构件、纹理和板式细节。有效分析与记录复用；只有相关变化才回查，不为套用本节重算已核指标或要求新表格。重要取舍按既定人机讨论节点处理。

## 把要求转成可核查的设计依据

- 先核对任务书和相关附件的身份、版本、实际已读页码/章节。保留影响方案或交付的原文位置、数值、单位和要求 ID；区分明确要求、偏好、推断及未知。不要把参考视频里的工具链或演示效果当作本机已具备的能力。
- 在现有项目契约/进度中以 `evidence` 和链接成果记录覆盖情况。关键要求较多时，简记：要求 ID、来源/版本/位置、原意及适用对象/分期/团队或个人、当前承诺、关联成果、能证明它的检查与尚缺内容。复用已有编号和记录；单个要求用一句话即可，不在严格顶层 schema 中随意加键。
- 对可能改变方案的矛盾、缺失尺度或假设，指出影响并提出可行处理。需要用户决定时只暂停依赖该决定的工作；有依据的部分继续推进。概念探索可以使用标明的假设，精确出图或合规判断不得悄悄补造条件。
- 当关键选型、造价或硬性限制依赖现行规范、材料技术资料或价格时，向主管机构、制造商或供应来源核实版本/日期及地域或产品适用性，并留下来源；未取得时按估算或未知处理。稳定资料及本项目已核实且仍有效的依据继续复用，不为普通修改重复全量检索。

## 在阶段转换时保留要求

- 开始深化、跨工具交接、处理实质反馈及交付时，只复核本次相关的仍有效要求、本轮承诺和未满足项。新的局部反馈通常补充或修正受影响内容；只有有依据的替代/取消才结束旧要求，注明来源与作用范围，不能因为最近没再提就丢弃。
- 分清项目总目标、分期任务、小组/个人归属和本次交付。当前不做不等于已满足或已豁免；在原记录保留延期/范围外/待核及原因或接续点。本轮局部任务可以独立完成，不为补齐全项目清单擅自扩大工作。
- 区分明确要求、偏好、探索方向、助手实施和推定条件；要求是否有效与成果是否已做/已核验分别判断。概念阶段按约定深度证明关系和取舍，工程阶段才要求相应精度；不把所有定性目标强制数值化或增设审批。
- 把易遗漏的语义转成足够的检查：例如“室内制作延伸至街巷”需要核查室内—开口—门前—通路的连续关系；“可继续编辑”需要读回和编辑结构证据；“住房容量”需要适用口径和来源，而非几个体块或标签。存在、外观、保存和局部碰撞检查各只证明自己的范围。
- 双向核对：本轮承诺是否各有对应成果与充分证据；交付成果是否实际回答原任务的对象、用途与格式。部分落实、未验证和明确延期分别说明，不能用本轮新增组件完成来宣称旧任务全部完成。来源未读全时，只声明已检查范围内的覆盖。

简短记录示例：`R07｜已采纳的近期通行要求｜门前至街巷｜本轮切穿入口｜模型rN＋截面/净距读回｜门组件已有，但贯通未核验，保持待查。` 示例字段可按任务缩减；不因存在这条记录就把要求判定通过。

## 先检验设计取舍，再增加细度

- 从本项目的使用需求、场地条件和设计意图选择最关键的问题。必要时接入 architecture-aesthetics 的参考学习或方案比较，保持长期偏好与项目风格分开。
- 用足以判断该问题的平面、剖面、体块、动线或面积检查支持决策；比较方案应采用同一场地边界、任务要求和指标口径。候选需要体现真正不同的取舍，数量由问题决定。
- 记录采用方向的依据和仍需验证的条件。方向未定时先让用户比较候选并共同选定，再在主技能约定的关键设计节点讨论；明确方向可直接推进当前阶段，不等于跳过后续尚未解决的重要取舍。用户明确授权自行选择或连续完成时按该授权执行，常规生产不增设确认。新工具链或成本较高的重复操作，可先用一个代表性片段检验衔接；已有可靠流程无需每次重做小样。

## 建模前按需补足参考

- 方向选定后，先判断现有依据能否说明关键形体、跨数/层数、屋顶、开口和相邻构件衔接。补图的目的是在动手建模前减少猜测、提高细节转译与还原度；建模后从模型导出视图检查执行结果是另一用途，不能代替这项准备。
- 不固定凑齐三视图、鸟瞰或细节套图。先复用已有平立剖、参考和尺寸；确有缺口时说明哪一张图/局部示意能解决什么、预计增加的调用或返工代价，再按已有授权采用最少够用的表达。需要生成时沿用用户模型/调用路径约束，不承诺未经实测的额度节省。
- 补图围绕同一采用版本、对象编号、朝向和可靠尺度锚点；检查体块对应、跨数/开口位置、屋面与连接是否跨视图一致。在现有进度标明整体控制图、局部补充及未决项，不按图片精美程度或生成先后覆盖已确认关系。图像之间的冲突先解决受影响部分，不把不同候选拼成一栋建筑；不能量测的尺寸、背面和构造仍按假设/未知处理。
- 将参考转成可执行的关键关系与尺寸依据；疑点可能造成大量返工时，先试一个代表性建筑/接口，量测实际几何并与相应参考比较。重要设计取舍带具体成果讨论，确认后再批量深化；可靠常规任务直接执行。生成的设计参考保留其来源和采用状态，仍是 `presentation_only`，模型精度须由可靠输入和成品核验支持。

## 让模型、图纸与彩平共用几何

- 按用户指定及编辑需求选择 SketchUp、Rhino 或 CAD 作为当前几何来源；通过有依据的单位和坐标转换协调楼层与稳定 ID。不同分期/候选可保留独立基底，按 [基底与身份](source-baselines.md) 记录各来源、精度、控制点、变换及残差；无可靠转换时只作示意，不为视觉对齐拉伸已确认构件。采用已有模型时先读取其真实状态与工作副本，不从聊天描述重建一套。
- 输出所需模型和 CAD 平立剖时沿用相同构件/楼层关系。跨工具交换要检查单位、原点、楼层和可能丢失的编辑语义；复用专业技能的数值、视觉、保存和重开核验。
- 彩平以已检查的当前平面导出为底，墙、开口、房间/功能边界和实际构件保持对应。精确线稿、文字、图例、尺寸等保留可编辑图层，并在成图中核对比例、指北针与标注；只保留用户实际需要的源格式。
- ImageGen 可用于允许变化的材质、植栽或氛围探索。核查结果是否改变几何边界；生成图不得作为量测依据，精确标签不得仅依赖栅格生成。方案探索允许提出几何变化，但需先更新所采用的几何来源，再更新协调成果。

## 指标从同一修订的对象和范围计算

- 指标表保留量测来源/修订、空间或边界 ID、面积口径、包含/排除项、公式、单位与目标来源。面积必须明确是净面积、总面积还是另一种定义；不同定义不能混加或互相代替。
- 优先从闭合平面边界、实际楼层/空间对象或明确的尺寸表量测，用本机脚本或公式复算。若只是概念估算，注明假设、精度和用途。不从效果图目测出精确指标，也不补造缺失分母。
- 核对分项与合计、重复/遗漏对象、平方米与毫米等换算。方案对比使用相同边界和计算规则；任务书目标和已核实适用规则分别标明。规则版本或适用性未知时保留未知，不能宣称法规合规。
- 只按交付需求采用可重算表格或结构化数据；若需要电子表格，调用相应技能。让公式和底层量测可追溯，不为简单回答额外生成 Excel。

## 按有效修订交付

- 模型/任务书变更时，按 [项目契约](project-contract.md) 追踪受影响图纸、彩平、指标和演示页，标明旧成果与失效检查。只重做受影响部分；旧成果的“通过”不能自动转给新方案。
- 在已有契约/进度中连接实际文件、检查和下一步。按照用户要求提供可编辑源文件及必要依赖，简述已核查与未验证范围；不以“整套完成”的一句话代替实际可用文件，也不把整套示范输出强加给只要其中一项的任务。
