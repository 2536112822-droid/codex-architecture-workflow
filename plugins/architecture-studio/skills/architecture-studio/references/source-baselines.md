# 基底、现状与方案身份

在选择/合并基底、用图补建、处理来源冲突或基底更新时读取。适用于任何建筑项目，覆盖场地资料、设计模型、CAD、指标和表现；只处理本次关键或变化对象，复用现有证据索引/契约，不要求每轮新建表格或数据库。

## 分别回答四个问题

| 维度 | 要明确的内容 | 不能据此推出什么 |
|---|---|---|
| 几何来源 | 哪个文件/修订、实际资料日期、适用部位、单位、坐标/高程/北向基准、精度与局限 | 最新文件或保存通过不等于测绘真实 |
| 现实证据 | 哪个具体主张由测量、照片或其他资料支持；推断/未知及证据有效日期 | 用户采纳设计不等于现场、产权或审批已核实 |
| 模型表示 | 已建、漏建、重建、简化、隐藏、仅示意；关联已有对象 ID | 新网格不等于新建工程；缺件/隐藏不等于现实不存在 |
| 设计用途与分期 | 保留、改造、拟建、拟拆或未定；哪个阶段/方案、依据及确认状态 | 远期候选不等于近期建设，技术实现不等于用户批准 |

这些是独立维度，不能压成一个“现状/新增/未知”互斥标签。例如补出被假定已有的屋盖：模型表示为补全，方案用途为保留，现实存在性仍可能未知。某个尺寸已确认，也不代表同一对象的屋顶、入口和产权同时确认。

记录在现有 evidence、element、artifact 允许字段或链接说明里；单个问题一句话即可。工具不支持这些语义字段时，保留旁置记录与对象关联，不虚构参数或强行修改全模型属性。

## 选择与配准

1. 按对象和用途确定控制来源：现实边界/测量、已确认设计、概念参考和技术交付各自回答不同问题，不制定“最新文件总是优先”的总排序。冲突影响决策时说明证据和取舍，保留未知。
2. 多个分期/候选可以保留各自基底。每个来源的单位、原点/CRS、北向及高程基准、资料日期与精度分别记录；局部技术契约不能自动扩成全项目坐标权威。
3. 需要几何叠合时，核实单位转换、控制点及平移/旋转/必要的尺度换算，保留变换和残差。检查依据满足当前用途；不得为贴图而任意缩放或拉伸受保护构件。无可靠转换时标为未配准或近似定位，不能通过修改标签宣称完成统一。
4. 图上的比例尺只能说明其声明的输出比例，不能提升来源精度。示意映射可用于解释关系；依赖精确位置、净距或面积的结论须另有足够依据。不阻止不依赖这些未知项的设计工作。

## 新来源如何传播

- 先比较修改部位、对象对应及配准变化，区分补充事实、纠错、设计变化和仅表现变化。发现新版不等于采用，也不自动授权覆盖原件或整个设计。
- 采用后按现有依赖规则追踪模型 → 平立剖/彩平 → 指标 → 渲染/演示中实际受影响部分。不同工具没有共同 ID 时，使用有依据的对应表或局部说明；对应不明先标待核查，不凭相似名字自动替换。
- 变化不只可能是几何：把屋盖从“拟建”改为“按既有保留”，即使网格不变，也可能影响分期图例、工程量及说明。核对这些受影响项；未变化的相机/几何等有效检查可复用。
- 只有实际应用并核验后才写“已同步”；文件路径存在、修改时间更新、用户未反馈或助手完成声明均不足以证明传播完成。遵守工作副本、单写入者和保存核验规则。

## 各环节怎样保持信息

- **场地与资料**：保留资料日期、覆盖、现实证据和未知；旧调查不能单独证明当前现场。
- **设计与建模**：保持分期及允许变化范围，补全与设计新增分别判断；保留对象关联和配准依据。
- **图纸与指标**：图例和测算范围与采用版本一致；不把隐藏/漏建转成拟拆，不把示意轮廓用于精确合规或工程量结论。
- **表现与交付**：生成图不成为测量证据；使关键的推定、未配准及分期状态可被下游理解。引用实际几何来源及相关检查，避免另画一套后失去来源。

## 最小情景复核

按本次改动选用，不每次全跑：补画漏失屋盖能否保留其现实未知；隐藏冲突管线是否仍待配准；远期体量是否混入近期工程量；较新调查改变邻楼时是否仅检查相关衔接/净距/出图；局部设计尺寸是否因贴合旧底图被误拉伸。规则检查只能证明表述是否覆盖风险，实际精度、设计质量和耗时需在真实任务中验证。
