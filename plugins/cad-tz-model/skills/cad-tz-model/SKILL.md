# AutoCAD + 天正建筑制图

## 文件保存与收尾

文件暂存、正式保存、中间数据保留与清理遵循当前全局 AGENTS.md 和本任务已有授权。已有授权或默认策略覆盖的事项直接执行，只询问仍缺少的必要决定；本节优先于下文及参考文件中的保存和保留默认值。


通过注入 AutoCAD 的 TzServer 协议桥，在 AutoCAD 主线程和数据库事务内创建可编辑实体。正常绘制优先使用 `cad_apply_plan`，利用其内置预检、原子几何提交和数值 QA。不要使用旧 COM/LISP 工作流。

## 连接与目标锁定

1. 先调用 `cad_discover`。只有一个实例时继续；多个实例时用 `cad_use_instance` 明确选择，禁止猜测。
2. 调用 `cad_ping` 和 `cad_state`，记录 `process_id`、`instance_id`、`document_id`、`revision`、单位、活动图层和命令状态。
3. 未连接时可调用 `cad_quickstart`；若天正未加载，先阅读可用的 Computer Use 技能并检查现有窗口，在入口和目标明确时使用已安装的 T30 天正建筑入口启动。保留现有图纸及未保存内容，不为加载插件反复重启。恢复后重新 `cad_discover`、锁定实例并读取 `cad_state`/`tz_status`；仅在入口不可用、目标不明或必须人工操作时请求用户协助。
4. 升级或首次启用时运行 `cad_selftest`。它只做协议 dry-run，不写测试实体。
5. 用户切换图纸或手工编辑后，旧 `document_id/revision` 失效；重新读取状态后再计划。

## 标准制图闭环

1. 把简报拆为轴网、墙体、柱、开口、楼梯、房间、标注和图框；明确图纸单位和目标比例。
2. 先定义图层、颜色、线型和中文文字样式。建筑尺度默认使用 mm，但必须显式写在 plan 中。
3. 计划明确且符合已核对的 schema 时，可用计划版本专属 `idempotency_key` 和最新 `expected_document_id/revision` 直接提交 `cad_apply_plan`。陌生操作、复杂或不确定几何、用户要求预览时，先独立 `dry_run: true`。正式提交始终内置无副作用预检、受保护的单位/图层/样式设置、原子几何写入和数值 QA；独立预检后仍须使用相同 operations 与有效版本保护。
4. 检查返回的 `validation` 和 `final_state`；证据充分时不重复同一检查。必要时调用 `cad_query`、`cad_count`、`cad_select` 和 `cad_validate` 定位重复线、零长线、退化多段线、未闭合轮廓、非零 Z 或缺失图层。
5. 用 `cad_zoom` 和 `cad_screenshot` 截取所选 AutoCAD 进程的窗口，再用 `view_image` 检查线型层级、文字、标注、比例、裁切和缺漏。
6. 只用 `cad_edit` 或新的小 plan 修复明确问题。验证受影响几何；显示、文字、标注、布局或可见几何变化时截图复查。同一阶段的连续小修正可合并检查，交付前完成数值和视觉验收。不要因局部错误重画整张图。
7. 需要防丢或验证的副本先用 `cad_save_as` 写入任务暂存区。正式保存依全局策略和本任务授权，使用已指定或确认的目录并展示成果；`fmt=dxf*` 必须生成真实 DXF，不改名冒充，也不默认覆盖。

结构化计划示例见 [plan-schema.md](references/plan-schema.md)，验收要求见 [quality-gates.md](references/quality-gates.md)。

反复修改规则排孔板的二维尺寸时，可按 [参数化构件](references/parametric-components.md) 从参数文件生成计划模板；仅在此类构件任务使用，提交仍走上述文档保护与制图闭环。

## 天正 T30

- 先调用 `tz_status`；用 `tz_cmds` 搜索准确命令名，常用命令见 [tz_commands.md](references/tz_commands.md)。
- `tz_cmd` 和专家级 `cad_command` 都是异步入口，只表示命令已入队。必须保存返回的 `job_id`，随后用 `cad_job` 检查 `completed/failed/cancelled`。
- 天正绘制命令可能打开对话框或等待点选。遇到交互状态时暂停后续命令，先用 Computer Use 检查已锁定实例的当前界面；参数和目标已明确、且符合界面操作规则时，可完成普通对话框或准确输入，每次操作后重新观察。需要未知设计决定、无法可靠定位或必须人工操作时才请用户协助；不得盲点、重复发送原写入命令或以屏幕像素猜测几何坐标。交互完成后检查原 `cad_job` 和 `cad_state`，确认任务终态及文档未切换，再继续制图。
- 天正自定义实体不能当作普通线段随意改写。先用 `cad_query` 确认类型，再选择天正编辑命令或可控的基础实体替代方案。

## 图像/草图转 CAD

- 先用 `view_image` 确认是扫描图、照片、透视图还是正投影；至少需要一个尺度锚点。
- 把可见事实、合理推断和未知项分开。不可见的墙厚、背面开口或层高不得伪装为确定值。
- 先画轴线/控制线和总轮廓，验证整体尺寸；再补墙体、开口、构件、文字和标注。
- 各建模阶段核对关键数值，并用必要视图验证可见结果；同一状态下可复用已有证据。视觉接近不等于 CAD 几何正确。
- 需要天正对象时，可以先用基础 CAD 图元完成可验证底图，再在能安全完成交互的阶段转换或补建天正对象；交付仍须满足用户要求的对象类型，不把基础图元当作已完成的天正对象。

## 安全边界

- 所有写入自动绑定当前 `document_id/revision`；版本冲突时停止并重新读取，不绕过保护。
- `cad_apply_plan` 提交必须提供计划版本专属的 `idempotency_key`；若响应丢失，用原键、原 plan 和原 revision 重试，系统会返回 `idempotent_replay` 而不会重复画图。不得把同一键用于不同内容。
- 几何批次在一个事务中写入，失败整体回滚；单位、图层和文字样式是预检后的受保护设置步骤，不宣称与几何处于同一数据库事务。
- 多开 AutoCAD 时必须先选实例；截图也只允许截取被选中的进程窗口。
- 未命名图纸不能用 `cad_save`；使用 `cad_save_as` 明确路径和格式。
- 除非用户明确要求，不覆盖已有 DWG/DXF，不清空图纸，不执行来源不明的命令字符串。

报告最终文件路径、格式/版本、单位、图纸 revision、实体/图层概况、QA 结果、截图路径和仍需人工确认的天正交互或设计假设。
