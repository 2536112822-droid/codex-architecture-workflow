# 天正命令使用说明

本公开版不包含从厂商帮助文件提取的完整命令表。天正是需要自行安装和授权的外部软件。

使用某项天正功能时，先在用户本机对应版本的命令帮助中核实命令名、参数、前置选择和对话框行为。不要把别的版本命令表当作当前接口。

- 优先通过结构化 CAD 计划完成通用实体、图层和标注。
- 需要天正专业对象时，依据当前安装版本提供明确命令，用异步调用查询完成状态，并检查实际图纸对象。
- `runtime/mcp/tz_cmds.json` 初始为空，命令搜索为空不等于软件没有该功能。可在本地按相同格式维护个人命令索引；不要将厂商整份帮助内容提交到本仓库。
- 普通对话框按已知参数处理；状态不明时先读回，不重复提交写入。

接入方法见仓库 `docs/BRIDGES.md`。
