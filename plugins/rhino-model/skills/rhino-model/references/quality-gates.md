# Rhino / Grasshopper 质量门

只检查本次操作适用的质量门，满足后才能把阶段标记为完成。完成前汇总已有证据，状态未变时不重复运行已通过的检查。无法验证的必要项目应报告为 `WARN` 或 `UNKNOWN`，不得猜测通过。

## 连接门

- 唯一目标 Rhino 窗口与文档已锁定。
- MCP 仅监听 `127.0.0.1:1999`，`describe_capabilities` 与 `get_document_summary` 返回成功。
- 文档名/路径、单位、公差、对象数、图层数和包围盒已记录。
- 已记录端口在任务开始时是否运行，以及本任务是否拥有停止它的权利。

## 参考证据门

- 采用方案及各参考身份明确且可读；同一方案允许图纸、尺度与多视图互补，关键矛盾已处理。区分真实尺寸、比例推断、透视畸变和未知项，不把候选混成一个依据。
- 直接保真比较有适用的基准和尽可能一致的投影/相机/裁切；无法对齐时只作注明范围的定性比较，尺寸另用几何核验。非视觉修改不强制新抓视图。
- 无可靠依据的曲面控制线、标高或尺度不能声称准确复刻；概念试做可采用明确标注且适用于本阶段的假设，尺寸关键结论保持待核。

## 写入门

- 写入范围、坐标、单位和预期对象数明确。
- 首次重要写入前已有可恢复完整副本。默认改不冲突的工作副本并核对活动路径、源文件未变；明确授权原位修改时，核对活动原件身份和修改前备份，不能要求修改后的原件仍保持旧hash。
- 每个关键对象具有唯一名称和返回 GUID；重复构件也能按批次追溯。
- 写入后重新查询状态；超时先查对象数与 GUID，不直接重试。
- 删除或替换只作用于明确 GUID。禁止以 `all=true` 作为一般清理方法。
- 最小修改已记录目标与非目标 GUID、图层、属性、材质和对象数；非目标状态保持不变。
- 重建曲面时先验证候选并迁移属性，再删除旧 GUID；不能验证则不替换。

## 几何门

- 必要对象通过有效性检查，曲线闭合、曲面方向、实体闭合状态符合任务要求。
- 关键长度、面积、体积和包围盒与设计目标及当前文档单位一致。
- 布尔、放样、扫掠、偏移或管道操作的输入与输出数量可解释，无意外残留输入副本。

## Grasshopper 门

- 图结构、组件类型、连接与参数值可读取并与意图一致。
- 解算完成且关键输出无错误；必要时检查画布和预览。
- 清空或删除操作有明确范围与可恢复副本。

## 视觉门

- 按任务需要检查透视、顶、前、右或用户指定视图。
- 检查缺件、穿插、悬空、法向/方向、比例、视图裁切与明显退化几何。
- 数值与视觉结果矛盾时不交付，先定位原因。

## 文件门

- 默认工作副本位于任务暂存区，已授权原位修改则保留可恢复备份；正式 `.3dm` 使用已指定或确认目录，原文件未被未经授权覆盖。
- 按主技能的实际保存方式核对活动路径：普通 `SaveAs` 切到输出，`SaveACopy` 保留原活动文档；`GeometryOnly` 按几何导出核验，不冒充保留图层/材质/单位等内容的完整文档或备份。三者均检查实际输出存在、非零、修改时间及所需内容；不因副本保存未切活动路径而盲目重试。复制交付查源文件未变；授权原位保存查修改后的输出与修改前备份。[官方行为依据](https://docs.mcneel.com/rhino/8/help/en-us/commands/save.htm)。
- 重要文件记录 SHA-256，并在不干扰活动文档的前提下重开或独立读取验证；未能重开时明确报告。
- 最终报告包含 Rhino 版本、文档单位、对象/图层摘要、关键 GUID、QA 结果、保存路径和限制。

## 收尾门

- 临时对象按 GUID 清理，最终对象数与预期一致。
- 仅由本任务启动且无共享使用者的 MCP 才执行 `MCPStop`；复用的既有桥接保持运行并报告所有权。
- Rhino 窗口只在本次创建且无未保存用户内容时关闭。
